# 2-3. 프론트엔드와 모바일 개발자의 경력

## 화면을 만드는 개발자에서 사업을 움직이는 개발자로

- 예전에 비해 사용자의 행동 데이터를 이해하고, 서비스 전환율을 높이며, 제품 개선 속도를 끌어올리는 핵심 직무로 평가받고 있음.
- **사용자 경험을 설계하는 기술 인재**
- DX 과정에서 화면과 앱 품질이 경쟁력의 중심이 되었음.

## React, Vue, TypeScript 개발자의 시장 평가

- 일본에서 **React**, **Vue**, **TypeScript**는 전통 강자
- **Next.js**, **Remix**, **React Native** 경험도 인정받고 있음
  - 서버 사이드 렌더링, 성능 최적화, 컴포넌트 설계 경험
- **Vue**는 일본 시장에서 여전히 강한 입지
  - 관리자 화면, 예약 시스템, 업무용 웹 애플리케이션
- **Nuxt.js** 또한 콘텐츠 서비스, 커머스, 미디어 플랫폼 분야에서 사용 중
- TypeScript는 기본 소양
  - 일본은 안정성과 유지보수를 중시하기 때문에 타입 기반 개발 경험을 높이 평가
- 포트폴리오에서 강조할 요소들
  - **구조 설계**: 폴더 구조, 상태 관리, API 계층 분리 방식
  - **성능 개선**: 번들 크기 축소, 렌더링 최적화, 이미지 최적화
  - **품질 관리**: 테스트, 린트, 타입 체크, 코드 리뷰 경험
  - **사용자 경험**: 로딩 처리, 오류 메시지, 접근성, 반응형 대응
  - **협업 방식**: 디자이너·백엔드 개발자와의 의사결정 과정
- 화려한 개인 프로젝트보다는 실제 운영을 고려한 코드에 더 큰 신뢰감을 가짐
- 로그인, 결제, 검색, 알림, 다국어 처리, 관리자 기능 등 실무 위주 기능들

## iOS와 Android 개발자의 경쟁력

- 일본은 모바일 결제, 배달, 여행, 중고거래, 만화·콘텐츠, 게임, 금융 앱 시장이 큼
- 사용자의 체류 시간이 길고 결제가 자주 발생하는 서비스의 경우 앱 품질이 매출되기 때문에 중요한 영역
- 앱 실행 속도, 크래시율, 푸시 알림 도달률, 결제 흐름, 앱스토어 평점은 모두 중요한 지표
- iOS 개발자는 Swift와 SwiftUI 경험이 중요
  - 기존의 UIKit를 SwiftUI로 전환할 수 있으면 더 좋음
  - Combine, async/await, MVVM, Clean Architecture 등 구조적 지식도 중요
- Android 개발자는 Kotlin 경험이 필수
  - Jetpack Compose, Coroutine, Flow, Hilt, Room, Retrofit 등 현대 Android 개발 스택도 경쟁력 확보에 유리
  - 크래시 분석, 메모리 누수 대응, 배포 관리 경험이 중요
- Flutter, React Native 등 크로스플랫폼 개발 경험도 빠른 출시가 필요한 신규 서비스에서 선호됨
  - 다만 일본은 장기 운영 안정성을 중요하게 봄
  - 따라서 네이티브 기능 연동, 성능 이슈, 앱 심사 대응, OS 버전별 예외 처리까지 설명할 수 있어야 함

## 사용자 경험을 이해하는 개발자가 강하다

- 화면이 사양서대로 동작하는 것과 사용자가 편하게 느끼는 것은 다름
- 버튼 위치, 입력 흐름, 오류 안내, 로딩 시간, 색상 대비, 터치 영역, 뒤로 가기 동작 등 세부 요소가 서비스 만족도를 좌우함
- 일본 서비스는 고객 응대와 품질 기준이 높은 편
- 감각적인 주장보다는 차분한 근거와 재현 가능 과정을 신뢰함

## 협업 능력은 기술력만큼 중요하다

- 협업 관련 면접 질문들
  - API 명세가 불완전할 때 어떻게 조율했는지
  - 디자인과 구현 사이에 차이가 있을 때 어떤 기준으로 결정했는지
  - 일정이 촉박할 때 우선순위를 어떻게 정했는지
- 합의 과정, 문서화, 리스크 공유 중시
- 코드 리뷰 때는 공격적이기 보다는 근거와 대안을 함께 제시하는 태도가 필요

## 포트폴리오에서 반드시 보여줘야 할 것

- 좋은 포트폴리오의 구조
  - 문제 정의
  - 기술 선택 이유
  - 구현 범위
  - 개선 경험
  - 운영 관점
- README를 충실히 작성하자
  - 실행 방법, 주요 기능, 기술 스택, 폴더 구조, 고민한 지점, 향후 개선 계획
