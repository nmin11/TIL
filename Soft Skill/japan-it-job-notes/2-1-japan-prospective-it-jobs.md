# 2-1. 일본에서 유망한 IT 직무 지도

## 직무 선택은 취업 가능성을 결정한다

- "어떤 회사"가 아닌, "어떤 직무"를 먼저 결정하자
- 시스템 현대화 수요 및 DX 수요를 고려하자

## 백엔드 개발자: 가장 넓은 채용 시장

- 대부분의 서비스는 서버와 DB를 중심으로 움직임
- 일본 SI 기업은 여전히 Java 수요가 높음
- 스타트업, 자체 서비스 기업은 Go, Kotlin, Ruby on Rails, TypeScript 선호
- DB는 MySQL, PostgreSQL, Oracle, Redis, Elasticsearch
- 백엔드 직무는 전공자 및 경력자에게 특히 적합
- SI 기업은 높은 일본어 수준 요구
- 글로벌 기업은 영어 중심인 경우가 많음

## 프론트엔드·모바일 개발자: 사용자 경험을 만드는 직무

- 프론트엔드는 일본에서 수요가 급증하고 있음
  - 최근 사용자 경험과 화면 품질을 중시하는 기업이 늘고 있음
- Vue를 많이 사용하지만, Reat, Next.js 비중도 높음
- 컴포넌트 설계, API 연동, 성능 최적화, 접근성, 유지보수 가능성
- 모바일은 Kotlin, Swift, Flutter 경험이 유용
- 두 직무는 포트폴리오의 영향력이 큰 편

## 클라우드·인프라 엔지니어: 일본 디지털 전환의 핵심

- 일본에는 아직 온프레미스 서버와 레거시 시스템을 운영하는 기업이 많음
- 클라우드 엔지니어는 네트워크 구조, 권한 관리, 비용 최적화, 모니터링, 백업, 장애 복구, 컨테이너 운영까지 이해해야 함
- AWS 기준: EC2, S3, RDS, VPC, IAM, CloudWatch, Lambda, ECS, EKS 서비스 경험 중요
- Terraform, Docker, Kubernetes, CI/CD, Linux 운영 경험이 있으면 유리
- 일본어가 비교적 중요한 편
  - 인프라 업무는 개발팀, 보안팀, 고객사, 운영팀과 협업하는 경우가 많기 때문

## 데이터·AI 엔지니어: 성장성은 크지만 진입 장벽도 높다

- 일본에서 가장 주목받는 직군
  - 비용을 줄이고 매출을 늘리는 데에 직결되기 때문
- 데이터 엔지니어: SQL, Python, Spark, Airflow, dbt, BigQuery, Redshift, Snowflake, Kafka 기술이 중요
- AI 엔지니어: Python, PyTorch, TensorFlow, scikit-learn, Hugging Face, Vector DB, MLOps 지식이 중요
- 관심이 있다 정도를 넘어 수학적 이해, 데이터 처리 경험, 모델 평가, 비즈니스 문제 정의 능력을 함께 봄
- 현업 부서와의 소통이 필수이므로, 일본어 및 영어 능력이 중요

## 보안 전문가: 부족하지만 검증이 중요한 직무

- 일본에서 앞으로 각광받을 직군
- 분야: 애플리케이션 보안, 인프라 보안, 클라우드 보안, 관제, 침해사고 대응, 거버넌스·컴플라이언스
- 네트워크, 운영체제, 웹 취약점, 암호화, 로그 분석, 악성코드, 보안 도구 사용 경험이 중요
- AWS 보안, IAM 설계, WAF, SIEM, EDR, 취약점 스캐너 경험이 높은 평가를 받음
- 자격증이 비교적 의미를 가짐
  - 보안기사, CISSP, CISA, CompTIA Security+, AWS Security Specialty
- 취약점 분석 보고서, 모의해킹 실습 기록, 보안 정책 설계 경험, 사고 대응 절차에 대한 이해가 함께 있어야 함
- 일본어가 상당히 중요
  - 보안 사고 보고서, 고객 설명, 내부 규정, 감사 대응 문서 작성

## 지원자 유형별 직무 선택 기준

- 전공자 신입: 백엔드, 프론트엔드, 클라우드 중 하나를 중심축으로
- 비전공자: 프론트엔드나 클라우드 입문 경로
- 경력 개발자: 기존 경력을 일본 시장 수요와 연결
- 일본어가 약한 경우: 코드와 산출물이 평가받기 쉬운 직무
  - 백엔드, 프론트엔드, 모바일, 데이터 엔지니어
