# 1-6. 자체 서비스 기업과 스타트업의 기회

## 자체 서비스 기업이 제공하는 커리어의 밀도

- 단순 구현자가 아닌, 제품 성장에 책임을 지는 기술 인재로 성장 가능
- DX 전환과 더불어 외국인 개발자 채용의 문도 넓어졌음

## 기술 선택권이 개발자의 몸값을 바꾼다

- 어떤 기술을 사용할지를 개발팀 내부에서 결정할 가능성이 높음
- 레거시 전환 경험을 쌓을 수 있음

## 제품 경험은 이력서의 무게를 만든다

- 실제 비즈니스에 어떤 기여를 했는지 강조
- 단순 개발 업무보다 문제 해결 능력을
- 숫자와 과정 중심의 어필 포인트 예시
  - 성능 개선: API 응답 시간을 800ms에서 300ms로 단축
  - 운영 안정화: 배포 자동화 도입으로 수동 배포 오류 감소
  - 사용자 경험 개선: 검색 필터 개편 후 상품 탐색 전환율 상승
  - 비용 절감: 클라우드 리소스 재설계로 월 운영비 절감
  - 협업 개선: 기획·디자인·개발 간 요구사항 정리 프로세스 구축

## 스타트업이 주는 빠른 성장과 높은 변동성

- 스타트업의 장점
  - 빠른 의사결정
  - 역할의 경계가 넓음
- 스타트업의 위험
  - 조직 구조가 자주 바뀌고 채용 계획이 변경될 수 있음
  - 복지 및 교육 체계가 불안정할 수 있음
  - 야근으로 인한 과로

## 한국 개발자에게 열리는 실질적 기회

- 한국 개발자는
  - 빠른 서비스 출시 및 개선 문화에 익숙
  - 모바일 중심 사용자 경험에 민감
  - 글로벌 기술 스택을 적극적으로 학습
  - 일본 문화 적응 비용이 낮음
- 영어 기반 문화가 형성되고 있음

## 선택 기준은 성장 가능성과 지속 가능성이다

- 기술 블로그, 채용 페이지, 엔지니어 인터뷰, 오픈소스 활동, 컨퍼런스 발표 자료를 통해 파악
- 연봉도 중요하지만 경험의 질을 함께 볼 것
- 입사 전 확인해야 할 기준들
  - 서비스 성장: 사용자가 늘고 있는가, 매출 모델이 명확한가
  - 기술 환경: 현대적인 개발 도구와 체계를 갖추었는가
  - 조직 문화: 개발자의 의견이 제품 결정에 반영되는가
  - 외국인 적응: 비자 지원, 언어 지원, 온보딩 경험이 있는가
  - 근무 지속성: 야근, 장애 대응, 업무 범위가 감당 가능한 수준인가
