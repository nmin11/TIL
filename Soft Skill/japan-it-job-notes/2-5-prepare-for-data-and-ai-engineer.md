# 2-5. 데이터와 AI 엔지니어의 기회

## 일본 기업이 데이터와 AI에 주목하는 이유

- 오랫동안 축적해 온 고객 정보, 제조 현장 데이터, 금융 거래 기록, 물류 흐름, 의료 및 보험 데이터 등을 보유하고 있음
- 하지만 일본 내 AI 전공자와 데이터 전문가가 부족한 상황
- 한국 개발자가 Python, SQL, 클라우드, 백엔드 개발 경험을 토대로 진출해볼 수 있는 영역

## 데이터 엔지니어: AI 시대의 기반을 만드는 직무

- 데이터 엔지니어는 데이터를 수집하고 저장하며, 분석 가능한 형태로 가공하는 역할을 맡음
- 데이터 파이프라인이 없으면 AI도 제대로 작동하지 않음
- 분산된 데이터를 통합하고, 클라우드 기반 데이터 웨어하우스나 데이터 레이크로 옮기며, 분석팀 및 AI팀이 사용할 수 있도록 정제해야 함
- 기본 역량: SQL 필수, Python을 활용한 데이터 처리 능력
- AWS, GCP, Azure 환경에서의 데이터 파이프라인 구축 경험도 경쟁력 있음
  - Apache Airflow, Spark, Kafka, dbt, BigQuery, Redshift, Snowflake 기술 경험

## 머신러닝 엔지니어: 모델을 서비스로 연결하는 인재

- 데이터 기반으로 예측 모델이나 추천 시스템, 분류 모델, 자연어 처리 모델 등을 개발하고 운영하는 직무
  - 연구자와 개발자의 중간에 있는 직무라고 볼 수 있음
- 모델 정확도보다도 비즈니스 문제 이해력이 필요
- 필요 기술은 Python 중심
  - Pandas, NumPy, scikit-learn, PyTorch, TensorFlow
- 대규모 언어 모델을 활용한 자연어 처리, 문서 요약, 챗봇, 검색 증강 생성 기술에 대한 수요 증가

## AI 응용 개발자: 가장 현실적인 진입 기회

- 이미 공개된 AI 모델과 API, 클라우드 AI 서비스를 활용해서 서비스를 만드는 역할
- 백엔드 및 웹 개발자가 전환하기 좋은 직무
- OpenAI API, Azure OpenAI Service, Google Vertex AI, Amazon Bedrock 등 활용

## 일본 시장에서 요구되는 역량의 조합

- 기술, 비즈니스 이해, 커뮤니케이션을 함께 갖춘 사람 선호
- 기술적으로는 3가지 축에 대해 준비
  - 데이터 처리 능력: SQL, Python, DB, ETL 경험
  - 클라우드 활용 능력
  - 서비스 개발 능력
- 비즈니스 밀접도가 있으므로 일본어 능력도 중요

## 취업 준비 전략과 포트폴리오 방향

- 반드시 결과물 중심으로 구성할 것
- 좋은 포트폴리오의 흐름
  - 문제 정의
  - 데이터 설명
  - 처리 과정
  - 기술 선택
  - 결과 검증
  - 서비스화
- 일본 채용 공고 분석 프로젝트가 요긴할 것
  - 채용 공고 데이터를 수집해 직무별 요구 기술, 지역별 연봉, 일본어 요건, 원격근무 가능 여부 분석 가능

## 데이터와 AI 직무가 여는 장기 커리어

- 이 직무들의 장점은 커리어 확장성이 크다는 점
- 현장 문제를 기술로 해결하는 인재로서의 가치
- 단기간에 완성되는 직무는 아니지만 SQL, Python부터 차근차근 진입할 수 있을 것
- 핵심
  - 데이터 엔지니어는 AI가 작동할 기반을 만듦
  - 머신러닝 엔지니어는 예측과 자동화의 지능 구현
  - AI 응용 개발자는 실제 서비스와 업무 시스템으로 연결
